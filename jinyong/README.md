# 金庸小说人物词向量分析

本项目基于TF-IDF模型，对金庸小说全集进行词向量训练，并对小说中的人物名称进行降维可视化。

## 项目结构

- `main.py`: 主程序
- `requirements.txt`: 依赖包列表
- `name.txt`: 金庸小说中的人名数据集
- `jinyong/`: 金庸小说全集
- `all.txt`: 合并后的全集文本（程序运行后生成）
- `tfidf_model.pkl`: 训练好的TF-IDF模型（程序运行后生成）

### 可视化输出文件
- `character_2d_overview.png/svg`: 人物词向量的2D概览可视化结果（仅标注部分人名）
- `character_3d_overview.png/svg`: 人物词向量的3D概览可视化结果（仅标注部分人名）
- `character_2d_part1_of_X.png/svg`: 人物词向量的2D分区可视化（标注所有人名，分多张图）
- `character_3d_part1_of_X.png/svg`: 人物词向量的3D分区可视化（标注所有人名，分多张图）
- `character_2d_no_labels.png`: 人物词向量的2D可视化（无标注）
- `character_3d_no_labels.png`: 人物词向量的3D可视化（无标注）
- `character_wordcloud.png`: 人物名称的词云图

## 功能说明

- 合并金庸小说全集到一个文本文件
- 使用jieba进行中文分词
- 基于TF-IDF训练词向量模型
- 提取人名的词向量
- 使用PCA进行降维，生成2D和3D可视化结果
- 生成中文人名词云图
- 支持中文字体显示，并使用多种保存格式确保中文正确显示
- **对所有人名进行可视化**：
  - 生成概览图（仅显示部分人名，便于快速浏览）
  - 生成分区图（将所有人名分成多个图，每张图最多显示200个人名）
  - 提供数据文件，可用于自定义分析和可视化


## 预期结果

- 通过词向量可视化，可以发现金庸小说中人物之间的关系
- 在2D/3D空间中，相似人物或相关联的人物会距离较近
- 可以观察到不同门派、不同小说中的人物聚类情况
- 词云图直观展示了金庸小说中的人物名称
- 通过分区图，能够查看和分析所有人物名称在向量空间中的分布
